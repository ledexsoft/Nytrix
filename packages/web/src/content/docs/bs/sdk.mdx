---
title: SDK
description: Type-safe JavaScript clients for Nytrix.
---

Nytrix provides two JavaScript packages. Use `@nytrix/client` to connect to a running server, or `@nytrix/sdk` to start an embedded server and client in the same process.

## Connect to a running server

Install the client package:

```bash
npm install @nytrix/client
```

Create a client by providing the server URL:

```ts
import { Nytrix } from "@nytrix/client"

const client = Nytrix.make({ baseUrl: "http://localhost:4096" })
const sessions = await client.session.list()
```

`baseUrl` is required. You can also provide a custom `fetch` implementation or request headers. The generated TypeScript API types are available from `@nytrix/client`.

## Start an embedded instance

Install the embedded SDK:

```bash
npm install @nytrix/sdk
```

Create an instance and close it when finished:

```ts
import { create } from "@nytrix/sdk"

const client = await create()
try {
  const sessions = await client.session.list()
} finally {
  await client.close()
}
```

`create()` starts an embedded Nytrix server and returns its client. Pass `CreateOptions` to configure plugins and other supported instance options.

## API types

The client package generates its request and response types from Nytrix's public API. See the [client source](https://github.com/ledexsoft/Nytrix/tree/dev/packages/client/src/promise/generated) for the generated definitions.
