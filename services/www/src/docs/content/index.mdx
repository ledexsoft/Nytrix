Nytrix is an open source AI coding agent. It’s available as a terminal-based interface, desktop app, or web app.


## CLI

The npm package uses a postinstall script to select the native `nytrix` binary for your platform. The Bun and pnpm commands
explicitly allow the required script; Vite+ requires no additional flag. The mise command requires mise 2026.10.9 or later;
older mise versions install an older Nytrix release.

Windows package managers are not supported.


Download a standalone CLI binary for your platform from [GitHub Releases](https://github.com/ledexsoft/Nytrix/releases).

## Desktop

Download Nytrix Desktop builds for your platform from [GitHub Releases](https://github.com/ledexsoft/Nytrix/releases).


## Web

Access the Nytrix web interface with the `nytrix pair` command.

```bash
$ nytrix pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Connect

Nytrix has built-in support for many LLM providers. You can connect to them
directly [in the TUI](/cli/providers) with `/connect`.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[OpenCode Console](/console).

You can also try [OpenCode Go](/console/go), a $10/month subscription
plan that grants you access to the best coding models.

## Customize

Make Nytrix your own by editing the [Nytrix config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). For terminal interface themes and keybindings, see [CLI
settings](/cli/config).
