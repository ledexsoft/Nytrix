---
title: "Commands"
description: "Reference for the nytrix command line."
---

Every command accepts `--help` for its full flag list, for example `nytrix run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ nytrix run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Nytrix review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @nytrix/cli
      - run: nytrix run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ nytrix run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ nytrix run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ nytrix run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ nytrix run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ nytrix run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ nytrix run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ nytrix run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ nytrix run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ nytrix mini
```

Continue the last session.

```bash
$ nytrix mini --continue
```

Start with a model and an initial prompt.

```bash
$ nytrix mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ nytrix mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ nytrix mini --help
```

## session

Manages sessions.

```bash
$ nytrix session list
```

Limit the list and print JSON.

```bash
$ nytrix session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ nytrix session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ nytrix session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ nytrix session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ nytrix session import session.json
```

Import into a specific directory.

```bash
$ nytrix session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ nytrix session --help
```

## auth

Manages AI providers and credentials.

```bash
$ nytrix auth list
```

List them as JSON.

```bash
$ nytrix auth list --format json
```

Log in to a provider.

```bash
$ nytrix auth login anthropic
```

Log in with a specific authentication method.

```bash
$ nytrix auth login anthropic --method key
```

Log out of a saved account.

```bash
$ nytrix auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ nytrix auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ nytrix auth export anthropic > credentials.json
$ nytrix auth import credentials.json
```

View all subcommands and flags.

```bash
$ nytrix auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ nytrix mcp list
```

Add a remote server.

```bash
$ nytrix mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ nytrix mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ nytrix mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ nytrix mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ nytrix mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ nytrix mcp logout sentry
```

View all subcommands and flags.

```bash
$ nytrix mcp --help
```

## plugin

Manages plugins.

```bash
$ nytrix plugin list
```

Include built-in server plugins.

```bash
$ nytrix plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ nytrix plugin add @example/nytrix-tui
```

Check package plugins for updates.

```bash
$ nytrix plugin check
```

Update package plugins.

```bash
$ nytrix plugin update
```

Remove a plugin from global configuration.

```bash
$ nytrix plugin remove @example/nytrix-tui
```

View all subcommands and flags.

```bash
$ nytrix plugin --help
```

Shows shareable usage statistics.

```bash

```

Show the last 7 days.

```bash
$ nytrix stats --days 7
```

Show model usage.

```bash
$ nytrix stats --models
```

Show cost and token details.

```bash
$ nytrix stats --cost
```

```bash
$ nytrix stats --json
```

Show only the current project.

```bash
$ nytrix stats --project .
```

```bash
$ nytrix stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ nytrix serve
```

Bind to all interfaces on a fixed port.

```bash
$ nytrix serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ nytrix serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ nytrix serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ nytrix pair
```

Use an external URL in the links.

```bash
$ nytrix pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ nytrix pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ nytrix pair --remote --yes
```

View all subcommands and flags.

```bash
$ nytrix pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ nytrix service start
```

Restart it.

```bash
$ nytrix service restart
```

Show its status.

```bash
$ nytrix service status
```

Stop it.

```bash
$ nytrix service stop
```

Read a setting.

```bash
$ nytrix service get hostname
```

Set a setting.

```bash
$ nytrix service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ nytrix service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ nytrix service set env NYTRIX_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ nytrix service unset hostname
```

View all subcommands and flags.

```bash
$ nytrix service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ nytrix reload
```

## api

Makes a request to the running server.

```bash
$ nytrix api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ nytrix api session.list --param limit=10
```

Send a JSON body.

```bash
$ nytrix api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ nytrix api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ nytrix api --help
```


```bash
$ nytrix acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ nytrix debug agents
```

List configuration sources.

```bash
$ nytrix debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ nytrix debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ nytrix debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ nytrix debug paths
```

Print a single path.

```bash
$ nytrix debug paths db
```

View all subcommands and flags.

```bash
$ nytrix debug --help
```

## upgrade

Upgrades Nytrix to the latest or a specific version. Alias: `update`.

```bash
$ nytrix upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ nytrix upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ nytrix upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Nytrix. Session data, configuration, and
state are not removed.

```bash
$ nytrix uninstall
```

Preview what would be removed.

```bash
$ nytrix uninstall --dry-run
```

View all subcommands and flags.

```bash
$ nytrix uninstall --help
```
